# 分平台发布检查清单

> 使用方式：发布前 48 小时逐项打勾，任何一项不过就不发。所有平台规则以官方最新文档为准。
>
> 本清单以**引擎无关项**为主。三引擎在构建环节的差异见文末「九、引擎构建配置对照」。

## 零、通用（所有平台必过）

### 包体与构建
- [ ] 正式构建使用 release 模式（关闭调试、关闭日志、开启混淆/压缩）
- [ ] 包体大小已测量并与平台上限对照，留出 ≥10% 余量
- [ ] 未引用资源已剔除（检查 resources 目录是否塞了不该塞的东西）
- [ ] 引擎模块已裁剪（未使用的 3D/物理/粒子模块）
- [ ] 纹理压缩格式按平台配置正确（不要在移动端用未压缩 PNG 当大图）

### 功能与稳定性
- [ ] 核心路径跑通：首启 → 新手引导 → 首胜 → 结算 → 再次进入
- [ ] 冷启动耗时在目标机型上达标
- [ ] 前后台切换、断网重连、进程被杀后恢复
- [ ] 长时挂机（≥30 分钟）无内存持续增长
- [ ] 低端机（目标机型下限）实机跑过，非模拟器

### 合规与素材
- [ ] 隐私政策可访问且与实际收集项一致
- [ ] 首次启动的隐私弹窗（如需要）在收集前弹出
- [ ] 实名与防沉迷（国内发行且适用时）
- [ ] 商店素材齐备：图标、截图、描述文案、宣传视频（如需要）
- [ ] 埋点与转化链路已校验（曝光、点击、启动、付费）

### 回滚
- [ ] 上一版本安装包/构建产物已归档
- [ ] 回滚步骤已写在发布单上，且有人能执行
- [ ] 服务端配置支持一键关闭新功能（如有灰度开关）

## 一、微信小游戏

- [ ] 主包体积在平台上限内（**复核：微信开放文档 · 分包加载**）
- [ ] 分包配置正确，分包在真机上能正常下载与加载
- [ ] 远程资源域名已加入白名单，且为 HTTPS
- [ ] 音频在首次用户交互后才播放，无静音启动问题
- [ ] 虚拟支付（如涉及）资质已具备，未使用违规支付路径
- [ ] 分享、录屏、排行榜等社交能力符合平台规范（无诱导分享）
- [ ] 胶囊按钮区域无 UI 遮挡
- [ ] 真机预览（iOS + Android 各一台）通过
- [ ] 体验版已上传并完成内部验收

## 二、抖音小游戏

- [ ] 主包体积在平台上限内（**复核：抖音开放平台 · 小游戏包体规范**，与微信数值不同）
- [ ] 分包配置与真机加载验证
- [ ] 广告 SDK 接入正确，激励视频回调可靠（涉及广告变现时）
- [ ] 侧边栏/推荐流入口的引导设计符合运营规范
- [ ] 内容与素材符合抖音内容审核标准
- [ ] 真机预览（iOS + Android）通过
- [ ] 体验版上传并完成内部验收

## 三、Android

- [ ] keystore 与上次发布**完全一致**（不一致将无法覆盖安装更新）
- [ ] versionCode 已递增，versionName 已更新
- [ ] targetSdk / minSdk 符合各商店当前要求
- [ ] 权限最小化，未申请与功能无关的敏感权限
- [ ] 隐私政策与数据安全表单已填写（Google Play 必需）
- [ ] 渠道包（如多渠道）已分别验证启动与支付
- [ ] 安装包在低端机安装与启动通过
- [ ] AAB（如发 Google Play）已通过本地 bundle 校验

## 四、iOS

- [ ] Bundle ID、证书、Provisioning Profile 三者匹配
- [ ] 隐私清单（Privacy Manifest）与用途说明字符串完整
- [ ] 数字内容支付走 IAP，未引导站外支付
- [ ] 未包含动态下发可执行代码的方案（热更新需合规设计）
- [ ] 静音键行为符合预期（AVAudioSession 类别已配置）
- [ ] 启动图、图标、截图符合 App Store 规范
- [ ] 审核备注写清了测试账号与复现路径（含内购测试说明）
- [ ] TestFlight 已完成外部/内部测试

## 五、HarmonyOS

- [ ] 使用的 Cocos Creator 版本明确支持鸿蒙构建（**必须核实版本支持矩阵**）
- [ ] 应用包名、证书、Profile 按鸿蒙流程申请完成
- [ ] 鸿蒙设备实机安装与运行通过（至少一台目标机型）
- [ ] 权限声明符合鸿蒙规范
- [ ] 华为应用市场素材与类目已准备
- [ ] 与 Android 版本的功能差异已记录（如有）

## 六、Windows

- [ ] exe 已签名（未签名易被杀软拦截）
- [ ] 安装包/压缩包在干净系统上解压即用
- [ ] 安装路径不含中文与空格时也正常（以及含中文时也不崩）
- [ ] 显卡兼容：至少验证集成显卡 + 独立显卡各一台
- [ ] 全屏/窗口切换、分辨率切换、多显示器场景正常
- [ ] 存档路径使用系统标准目录，不写程序目录

## 七、Web

- [ ] 首次加载体积已优化（引擎 + 首场景资源）
- [ ] 资源服务器 MIME 类型正确（.wasm / .bin / .json）
- [ ] 缓存策略合理（HTML 不缓存、带 hash 的资源长缓存）
- [ ] 跨域资源 CORS 配置正确
- [ ] 移动端浏览器（iOS Safari / Android Chrome）实测通过
- [ ] 音频在用户交互后启动（浏览器自动播放策略）
- [ ] 页面失焦/切后台时暂停逻辑正确

## 八、Linux

- [ ] 引擎版本对 Linux 构建的支持已核实
- [ ] 依赖库版本在目标发行版上可用（glibc 版本下限）
- [ ] 可执行权限与启动脚本正确
- [ ] 至少两个主流发行版（如 Ubuntu LTS + 另一发行版）实测
- [ ] 存档路径遵循 XDG 规范
- [ ] 若上 Steam：Steam Runtime 兼容性已验证

## 九、引擎构建配置对照

三引擎在构建阶段的差异，逐项确认后再执行上面的平台清单。

### Cocos Creator
- [ ] 构建面板选择正确的构建目标（小游戏 / 原生 / Web）
- [ ] 引擎模块裁剪已勾选（未使用的 3D / 物理 / 粒子模块）
- [ ] MD5 Cache 与资源压缩配置符合发布要求
- [ ] 小游戏分包在构建面板正确配置，且首包体积已核对
- [ ] 原生构建的 keystore / 证书配置与上次发布一致

### Unity
- [ ] 使用 Release 配置构建，Development Build 与 Script Debugging 已关闭
- [ ] Managed Stripping Level 与 `link.xml` 已核对（防反射/序列化类型被裁）
- [ ] Addressables 已执行 Build → Update a Previous Build 或全新构建，远端目录已上传
- [ ] 纹理压缩按平台 Override 正确（Android ETC2/ASTC、iOS ASTC）
- [ ] 小游戏目标（如走转换工具链）已用最新版转换工具，转换后包体与帧率已实测
- [ ] IL2CPP + 目标架构（ARM64 / ARMv7）配置正确
- [ ] 启动画面、包名、版本号、图标已更新

### Godot
- [ ] 编辑器版本与 export templates 版本**完全一致**（不一致会直接构建失败）
- [ ] 导出预设（export_presets.cfg）中包名、版本号、图标已更新
- [ ] 导出过滤（Export Filters）已排除不需要的资源
- [ ] C# 项目（如使用 .NET 版）已确认目标平台的导出支持状态
- [ ] Android 导出：keystore、min/target SDK、架构（arm64-v8a）已配置
- [ ] PCK 补丁与资源更新方案（如需要）已设计并验证
- [ ] 发布构建关闭调试输出与编辑器功能（remote debug 关闭）
